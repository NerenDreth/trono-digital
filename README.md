# Trono Digital 👑
Plataforma de subasta por espacio digital

## Descripción
Trono Digital es una aplicación web con una mecánica de puja única.
Un usuario paga para ocupar el espacio principal y publicar lo que quiera.
Si otro usuario quiere ese espacio, paga el doble — y el dueño anterior
recupera la mitad de lo que pagó originalmente.

## Tecnologías
- Node.js
- Express
- JavaScript
- HTML & CSS

## Características
- Sistema de pujas con mecánica de reembolso parcial
- Registro de usuarios
- Historial de transacciones
- Interfaz responsive
